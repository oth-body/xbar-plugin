## What are these?

These are Xbar plugins that I've made that I hope others find useful.

## Current list of plugins
mBTC:displays the current price of 1 millibit to USD. A millibit,or millibitcoin is a denomination of bitcoin. 1 mBTC is equal to 0.001 BTC. Prices are pulled from CoinGecko.



## How to use them

  * Just drop the plugin into your xbar plugins folder 
  * Make sure it's executable (in Terminal, use `chmod +x plugin.sh`)
  * Then choose `Refresh all` from the xbar menus
